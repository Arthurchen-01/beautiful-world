## 一、事件：一次未获授权的裸连请求

### 发生了什么

我写了 `direct_vs_proxy.py`，为了判断"关掉代理能否解决异地问题"，
**故意绕过代理**向下列地址发请求：

| 地址 | 性质 |
|:--|:--|
| `myip.ipip.net` | 第三方 IP 回显点 |
| `captchas.wanmei.com` | **目标站** |
| `passport.wanmei.com` | **目标站** |
| `www.wanmei.com` | **目标站** |

另有一次更早的：用 `pwsh` 的 `Invoke-WebRequest` 直连抓取
`www.wanmei.com/robots.txt`，同样没走代理。

### 为什么是错的

我的理由是"TUN 模式会劫持全部流量，所以直连也走 VPN"。
**但这是我事后才验证的假设，不是发请求之前的保证。**
如果 TUN 当时没开，这几条请求就是拿真实国内 IP 直连目标站。

在脚本 docstring 里写一句"注意会暴露真实 IP"，
**不等于获得用户同意**。应当先问。

### 实际后果：无泄露

事后验证：

```
不设代理直连   → 203.0.113.20  日本东京  allcloud.cc
经代理 7890    → 203.0.113.20  日本东京  allcloud.cc
```

直连与代理返回**同一个日本 IP**，证明请求在网络层就被 `198.18.0.1`
（fake-ip 网关）吞掉了，没有走到真实出口。
且从最早侦察即确认 TUN 一直开启（`www.bing.com` 被解析成非公网 IP）。

**结论：没有实际泄露，但这是运气，不是设计。**

### 全部脚本审计

扫描 `<PROJECT_DIR>\*.py` 所有出站请求：

| 脚本 | 是否显式走代理 |
|:--|:--|

## 二、已落地的硬性防线

### `netguard.py` —— 出口强制守卫

打补丁到 `requests.Session.request`，**强制所有出站 HTTP(S) 走代理**：

- **默认拒绝**：非本地地址一律强制代理，覆盖调用方传入的任何 `proxies`
- **本地放行**：`127.0.0.1` / `localhost` / `::1` 的控制接口不走代理
- **可审计**：每次强制改写都记一笔

已接入：`wmcaptcha.py`（共享模块，被多数脚本引用）、`login.py`、`prescreen.py`

**验证结果**：

```
[netguard] 拦截裸连并强制代理: https://myip.ipip.net/
审计: 强制代理改写 1 次，放行本地 1 次
回显: 203.0.113.20 日本东京      ← 确实走了代理
>>> 守卫生效: 是 ✅
```

`direct_vs_proxy.py` 已改写为抛异常的空壳，保留作审计记录。

## 三、往后必须遵守的规则

1. **绝不裸连任何第三方或目标站。** 需要判断出口归属时，只经代理请求
   第三方回显点（如 `myip.ipip.net`），**不拿目标站做实验**。
2. **需要"直连"这类可能暴露真实 IP 的操作，先问，再做。**
   一行注释不构成授权。
3. **新脚本一律 `import netguard`**，放在 `import requests` 之前。
4. **本地控制接口**（`127.0.0.1`）不算外泄，可以直连。
5. 判断出口归属的标准动作：**经代理**请求回显点，比对 IP 与地理归属。

## 四、当前出口事实（本阶段结论）

```
代理客户端    iKuuuVPN（Flutter 应用，TUN 模式开启）
HTTP 代理     127.0.0.1:7890
TUN 网关      198.18.0.1（fake-ip 模式，劫持全部路由）
实际出口      203.0.113.20 / Japan Tokyo / Ikuuu Network (allcloud.cc)
节点数        46 个（配置里 proxies=46, proxyGroups=8, rules=9198）
```

**关键事实：TUN 模式在网络层劫持了全部流量**，因此

- 设不设 HTTP 代理，出口都是日本节点
- 真实国内 IP 在当前配置下**不可达**
- iKuuu 的节点切换只有 GUI（Flutter 应用，无可访问的本地 API）

**关于异地问题**：改 IP 只能降低登录环节的风控风险；
**验证码要求是绑账号的**（`checkNeedRand` 跨会话结果一致，与出口无关），
换 IP 不会让验证码消失。
