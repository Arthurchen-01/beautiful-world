  完美世界扫号工具 · 使用说明
════════════════════════════════════════════════════════════


【一】这是什么

  输入一批「账号 + 密码」，自动登录完美世界，查出每个账号
  在哪些区服有角色、角色多少级，输出成一张表。


【二】怎么开始（三步）

  第 1 步  双击「完美世界扫号工具.exe」

  第 2 步  填两个东西：
           ┌──────────────────────────────────────────┐
           │ ① 账号   [✎ 手动]  ← 点这里粘账号密码     │
           │ ② 代理   [✎ 手动]  ← 点这里粘代理 IP      │
           └──────────────────────────────────────────┘

           账号格式（一行一个）：
              账号----密码
           例：<ACCOUNT>----<PASSWORD>

           代理格式（一行一个）：
              host:port:用户名:密码
           例：us.proxy.example:3010:user-region-JP-sid-XXXX-t-5:password

  第 3 步  点【环境自检】→ 等三项都显示 ✅ → 点【▶ 开始扫描】

  跑完点【打开结果】就能看到表。


【三】界面上的每个东西

  ┌─ 输入区 ──────────────────────────────────────────┐
  │ ① 账号     ✎ 手动 = 直接粘     选文件 = 从 txt 读  │
  │            ⚙ 处理 = 先体检（查重、看多少条能用）   │
  │ ② 代理     ✎ 手动 / 选文件 / ⚙ 处理（含测存活）    │
  │ ③ 结果     默认存在程序同目录的「结果.txt」         │
  │            「另存为」可以改地方                     │
  │ 代理API    粘贴代理提取网址，「拉取」一键获取       │
  └───────────────────────────────────────────────────┘

  ┌─ 参数区 ──────────────────────────────────────────┐
  │ 游戏     auto = 自动识别（推荐，不用改）            │
  │ 并行     同时跑几个账号。有代理池可以开 4~8         │
  │ 限速     两次请求的最小间隔，0.8 秒最好，别改小     │
  │ 重试     网络不好时的重试次数，默认 3               │
  │ 多IP代理池  勾上才用代理                            │
  │ 详细日志  勾上会显示内部过程，排查问题用            │
  └───────────────────────────────────────────────────┘

  ┌─ 按钮 ────────────────────────────────────────────┐
  │ 环境自检   开工前点一下，确认三件事都正常           │
  │ ▶ 开始扫描  开始干活                                │
  │ ■ 停止      中途停下（没跑完的会记住，下次接着跑）  │
  │ 打开结果    打开结果表                              │
  │ 数据目录    打开日志文件夹（出问题时用）            │
  └───────────────────────────────────────────────────┘


【四】进度条怎么看

  扫描开始后，进度条下方会显示：

     3/6  (50%)   成功 2   失败 1   时速 48/时   已用 1.5 分   剩余约 1.6 分

  含义：
      3/6        跑完 3 个，一共 6 个
      成功 2     拿到结果的
      失败 1     没拿到的（右边会写原因）
      时速       每小时能跑多少个
      剩余       预计还要多久

  失败原因会说人话：
      密码错误        账号密码不对
      网络不稳，可重跑  代理断了，会自动换一条重试
      账号被封        被封了
      账号被锁        被锁了


【五】日志怎么看

  默认只显示「一个账号一行」的简洁进度：

      [1/6] zhangsan@163.com   出口 JP/Osaka  2786ms
         [识别] 玩过: [完美世界]  -> gameId [1]
         扫描进度 30/53 区服（命中 12，待重试 1）
      [1/6] ✓ 成功  zhangsan@163.com   4 区服 / 8 角色   202 秒
      [2/6] ✗ 失败  lisi@qq.com   密码错误   9 秒

  想看内部细节就勾上【详细日志】。


【六】出问题了怎么办

  1. 点【环境自检】，看哪一项不是 ✅

  2. 点【数据目录】，打开这些文件：
        crash.log    程序崩溃的记录（发给技术人员看这个）
        scan.log     完整运行日志
        fail.csv     失败账号清单

  3. 常见情况：
       ❌ 识别服务起不来   → 重启软件，一般会自己好
       ❌ 出口检查不过     → 检查 VPN/代理软件是不是开着
       ❌ 全是「网络不稳」 → 代理池质量差，换一批代理
       ❌ 一直「重试中」   → 正常，说明触发了验证码在自动解，
                            会自动换代理重试；实在不行就把「重试」调大


【七】注意事项

  · 一次别跑太多，**并行数不要超过 8**（实测超过会被风控）
  · 跑过的账号会自动记住，下次不重复跑（想重跑点【⚙ 处理】里取消勾选）
  · 结果文件默认在软件同目录的「结果.txt」
  · 软件第一次运行会解包识别引擎，会慢一点（约 10 秒），之后就快了


【八】命令行用法（可选，给懂技术的人）

  完美世界扫号工具.exe --selftest          环境自检
  完美世界扫号工具.exe --e2e --accounts 账号.txt --proxies 代理.txt
  完美世界扫号工具.exe --cli 账号.txt --out 结果.txt --parallel 4 --proxy-file 代理.txt
