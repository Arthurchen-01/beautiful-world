# 完美世界扫号工具 · 一页说明书

## 三步就能跑

```
1. 双击  完美世界扫号工具.exe
2. 粘账号、粘代理（各点一次「✎ 手动」）
3. 点「环境自检」→ 三个勾都绿了 → 点「▶ 开始扫描」
```

跑完结果在 exe 旁边，文件名叫 **`结果.txt`**。

---

## 结果长什么样

```
账号----密码----[区服----等级----等级…----[区服2----…
```

例：

```
zhangsan@163.com----mypass----[经典区-天上人间----100----[校园区-御龙----30----120]
```

翻译过来就是：**这个号在「经典区-天上人间」有个 100 级的角色，在「校园区-御龙」有个 30 级和一个 120 级的角色。**

## 代理怎么填

**一条代理一行**，格式：

```
地址:端口:用户名:密码
```

三种都支持，程序自己认：

| 类型 | 长这样 |
| :-- | :-- |
| 普通 HTTP 代理 | `1.2.3.4:8080` |
| 带账号密码 | `1.2.3.4:8080:用户名:密码` |
| **住宅代理（推荐）** | `us.xxx.com:3010:user-region-JP-sid-XXXX:密码` |

**没有代理行不行？** 不行。程序每次启动都会检查出口，出口在国内就**拒绝开工** ——
这是防止暴露我们自己的 IP，别绕过。

## 常见问题

**问：能开多少并发？**
答：**看你有多少条代理。一个账号配一条 IP，不共用。**
代理有 100 条，就能开 100 并发。代理只有 8 条，就只能开 8。

**问：同一个账号能同时跑两个吗？**
答：不行，会被对方踢下线。**一个账号同一时刻只能跑一次。**

**问：跑得慢怎么办？**
答：先看「时速」那个数。慢的话通常是**代理线路慢**，不是软件慢。
换个更快的代理，或者把程序放到离目标近的服务器上跑。

**问：能跑 Windows Server 吗？**
答：能。Server 2019 / 2022 都行。**装的时候必须选「桌面体验」版，不能选 Server Core**
（Server Core 没有图形界面，跑不了）。

**问：服务器要显卡吗？**
答：不要。Windows 自带软件渲染，没显卡也能跑。

**问：能跑多少量？**
答：理论上不封顶，**取决于代理池多大、线路多快**。
详细测算见 [`产能分析_能跑多快卡在哪.md`](产能分析_能跑多快卡在哪.md)。

## 出问题先看这个

程序目录下有个 **`logs`** 文件夹（或 exe 旁边的 `scan.log`）。
里面有每一行在干什么。**把最后 20 行发我**，就能定位。

如果程序闪退没反应，看 **`崩溃日志.txt`**。

## 命令行用法（不想点界面的话）

```bat
完美世界扫号工具.exe --cli 账号.txt --out 结果.txt --proxy-file 代理.txt --parallel 16
```

| 参数 | 意思 | 建议值 |
| :-- | :-- | :-- |
| `--parallel` | 同时跑几个账号 | **= 你的代理条数** |
| `--workers` | 一个账号内部同时问几个区服 | 3 |
| `--rate` | 两次请求之间最少隔几秒 | 0.8 |
| `--timeout` | 单个请求最多等几秒 | **60**（住宅代理慢） |
| `--retries` | 网络失败换代理重试几次 | 3 |

## 服务器上怎么部署

一条命令，它会自己检查环境、铺文件、设定时任务：

```powershell
.\tools\deploy_server.ps1 -Exe "完美世界扫号工具.exe" -Accounts "账号.txt" -Proxies "代理.txt"
```

**先加 `-DryRun` 干跑一次**，它只体检、不改任何东西，会告诉你这台服务器行不行。

它会重点检查两件事：
1. **Media Foundation + Direct3D 11 在不在** —— 这套 OCR 引擎离了这两个跑不起来
2. **是不是 Server Core** —— 是的话得重装成「桌面体验」版
